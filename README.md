# Asphalt Tonnage Calculator

This is a simple website built to estimate the tonnage of asphalt needed for a paving project.

## What It Does

The website estimates how many tons of asphalt are needed for a paving project.

The user enters:

- Length in feet
- Width in feet
- Thickness in inches

The calculator then gives an estimated asphalt tonnage.
The calculator will give an error message if any field is blank, zero, or negative.

## Formula

tons = length x width x thickness in feet x 145 / 2000

The calculator uses 145 pounds per cubic foot as an estimated asphalt density.

## What I Used

This project uses:

- HTML for the page structure
- CSS for simple styling
- JavaScript for the calculator
- `hps-logo.png` for the header logo

## How To Open

Open `index.html` in a web browser to use the calculator. No installation or build step is needed.
